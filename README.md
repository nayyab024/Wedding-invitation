# Nayyab Wedding Card

A digital wedding invitation card for Nayyab's wedding.

## Overview

This project holds the design and source files for the wedding invitation. Guests can view it in a browser or receive it as a shareable image or PDF.

## Event Details

- **Bride:** Syeda Nayyab Fatima
- **Groom:** Syed Abu Turab Haider Naqvi
- **Event:** Barat, Monday, 30 November 2026, Night
- **Programme:** Arrival of Barat 7:00 pm · Nikkah 7:30 pm · Dinner 8:30 pm · Rukhsati 9:00 pm
- **Venue:** Al-Siddique Banquet Hall, F753, 754, Sidiqqui Chowk 6th Rd, Block F, New Katarlan, Satellite Town, Rawalpindi

## Project Structure

```
nayyab Wedding Card/
├── README.md        # This file
├── index.html       # Invitation page (envelope intro, hero, blessing, scratch reveal, Barat, closing)
├── css/style.css    # Styles, animations, and the color palette (:root variables)
└── js/main.js       # Couple config, envelope, petals, sparkles, scroll reveal, countdown, scratch card, .ics
```

## Getting Started

1. Open `index.html` in any modern web browser.
2. To share online, host the folder on a static host such as GitHub Pages, Netlify, or Vercel.

## Customization

- **Names:** edit the `GROOM` object at the top of `js/main.js`.
- **Colors:** update the `:root` variables in `css/style.css`.
